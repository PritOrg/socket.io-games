# Paper-like Theme & Dark Mode Implementation Plan

## Overview

The project currently has a basic "paper" theme but lacks proper dark mode support. The UI is currently too white and needs:

1. Enhanced paper-like styling with better texture/visual depth
2. Complete dark theme variant
3. Theme toggle functionality

## Current State Analysis

### Existing Theme Elements (`pro/src/index.css`)

- Hand-drawn fonts: Permanent Marker, Schoolbell, Caveat, Patrick Hand
- Paper background class (`.bg-paper`) with subtle texture
- Sketch components: `.sketch-card`, `.sketch-button`, `.sketch-border`
- Ink color variable (`#2a2a3e`) for dark text

### Issues Identified

- `body` uses pure white gradients (`rgba(255, 255, 255, 0.9)`)
- `glass` class uses white backgrounds
- No dark theme class definitions exist (references to `paper-dark` undefined)
- No theme toggle mechanism exists

## Implementation Plan

### Phase 1: Theme System Foundation

1. **Create Theme Context** (`pro/src/context/ThemeContext.jsx`)
   - Theme state: `'light'` | `'dark'`
   - Persist preference in localStorage
   - Default to `light` theme
   - Provide `toggleTheme()` function

2. **Update Index.css** with dark theme variables
   Add CSS custom properties for both themes:

   ```css
   :root {
     --color-bg: #f5f1e8;
     --color-paper: #fffef9;
     --color-ink: #2a2a3e;
     --color-accent: #8b7355;
   }

   [data-theme='dark'] {
     --color-bg: #121212;
     --color-paper: #1e1e1e;
     --color-ink: #e0e0e0;
     --color-accent: #c9b69c;
   }
   ```

3. **Add Dark Theme Styles** to `index.css`
   - `.bg-paper-dark` for dark paper backgrounds
   - `.sketch-card-dark` variant
   - Update `body` to respect theme

### Phase 2: Component Updates

1. **GameLayout.jsx**
   - Use theme-aware background classes
   - Update nav border color

2. **PaperPartyLanding.jsx**
   - Replace `glass` with theme-aware card styling
   - Add theme toggle button in header

3. **SketchButton.jsx** & **SketchCard.jsx**
   - Add dark theme variants automatically via CSS variables

4. **Bingo.jsx, TicTacToe.jsx, etc.**
   - Update hardcoded colors to use theme variables
   - Replace `text-gray-500`, `text-gray-800` with theme-aware classes

### Phase 3: Theme Toggle UI

1. **Add ThemeToggle component** to landing page header
   - Toggle between sun/moon icons (lucide-react)
   - Animated transition between themes
   - Persist preference across sessions

### Phase 4: Testing & Polish

1. Verify all game pages work in both themes
2. Check contrast ratios for accessibility
3. Test localStorage persistence
4. Run `npm run lint` and `npm run format`

## Design Decisions

1. **CSS Variables over Tailwind config**: Easier to maintain and toggle dynamically
2. **Data attribute selector**: `data-theme='dark'` on root element
3. **Paper-dark colors**: Charcoal backgrounds (`#121212`) with light paper cards
4. **Toggle placement**: Landing page header, visible but unobtrusive

### Confirmed Choices

- **Dark theme palette**: Charcoal (#121212 background, #1e1e1e cards) for a modern dark mode look
