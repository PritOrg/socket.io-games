# Codebase Review Plan

## Summary

The codebase is a monorepo with two packages:

- **`api/`** — Node.js Express + Socket.IO server with 4 game managers (Bingo, Dab, TicTacToe, UTTT)
- **`pro/`** — React 18 + Vite frontend with corresponding game components

All games follow a pattern: manager extends `BaseManager`, handles socket events, manages room state in Maps.

---

## Critical Issues (P0 - Hotfix)

### P0.1 `dab.js` — Duplicate Methods

**Location**: `api/game-logic/dab.js` lines 189-408

**Problem**: Multiple methods are defined twice:

- `requestRedo`: lines 189-233 and 304-348 (70 lines duplicated)
- `respondRedo`: lines 235-302 and 350-408 (79 lines duplicated)
- `handleDisconnect`: lines 596-652 and 654-705

**Critical Logic Bug**: The two `handleDisconnect` versions have inverted logic:

- v1 (line 611): `if (canContinue)` emits "game continues" message
- v2 (line 651): `if (!canContinue)` starts forfeit timer

**Action**: Remove duplicate definitions. Keep and fix v1 logic.

### P0.2 `ErrorBoundary.jsx` — Missing MUI Dependency

**Location**: `pro/src/components/ErrorBoundary.jsx`

**Problem**: Uses `@mui/material` which is not in `pro/package.json`

**Action**: Rewrite using plain HTML + Tailwind classes.

### P0.3 `TicTacToe.test.jsx` — Placeholder Test

**Location**: `pro/src/tictactoe/TicTacToe.test.jsx`

**Problem**: Contains only `expect(true).toBe(true)`

**Action**: Write real tests following `UTTTGame.test.jsx` pattern.

### P0.4 Dead Dependencies

**Location**: `package.json` files

**Remove from `api/package.json`**:
