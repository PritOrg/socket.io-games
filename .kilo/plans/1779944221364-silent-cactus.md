# Unified Game Lobby & UI Components Plan

## Overview

Create a unified waiting lobby UI, common room management, shared scoring/turn system, persistent player profile with icon avatars, and dark theme support across all games.

## Phase 1: Persistent Player Profile System (GameContext Enhancement)

### Task 1.1: Extend GameContext with Profile Persistence

**File**: `pro/src/context/GameContext.jsx`

Add persistent profile state (localStorage for name, avatar icon, color):

```jsx
const [profile, setProfile] = useState(() => {
  const saved = localStorage.getItem('playerProfile');
  return saved
    ? JSON.parse(saved)
    : {
        name: localStorage.getItem('playerName') || '',
        avatarIcon: 'cat',
        color: '#2a2a3e',
      };
});

useEffect(() => {
  localStorage.setItem('playerProfile', JSON.stringify(profile));
}, [profile]);
```

### Task 1.2: Create usePlayerProfile Hook

**File**: `pro/src/hooks/usePlayerProfile.js` (new)

**File**: `pro/src/components/ui/AvatarReactionBar.jsx` (new)

**Leave Room**: Clear `sessionStorage.<gamePrefix>_reconnect`, redirect to landing. No auto-rejoin on page refresh.
