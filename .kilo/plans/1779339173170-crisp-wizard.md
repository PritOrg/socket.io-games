# Comprehensive Fix for DAB (Dots & Boxes) Game

## Bugs Identified

### 1. Loading State - No Room Creation/Join UI

**File:** `pro/src/dab/DabGame.jsx` lines 361-370

- Shows "Connecting..." with no buttons to create/join a room
- Missing `handleCreateRoom` and `handleJoinRoom` functions

### 2. Event Name Mismatches (Critical)

| Component | Emits              | Should Be             |
| --------- | ------------------ | --------------------- |
| Backend   | `dab_redoRequest`  | → `dab_redoRequested` |
| Frontend  | `dab_approveRedo`  | → `dab_respondRedo`   |
| Frontend  | `dab_denyRedo`     | → `dab_respondRedo`   |
| Backend   | `dab_redoAccepted` | → `dab_moveUndone`    |

**Verification:**

- Backend line 174: `dab_redoRequest`
- Frontend line 253: listens for `dab_redoRequested`
- Backend line 14: listens for `dab_respondRedo`
- Frontend lines 707, 717: emit `dab_approveRedo`/`dab_denyRedo`
- Frontend line 264: listens for `dab_moveUndone`
- Backend line 214: emits `dab_redoAccepted`

### 3. Crash Bug in Redo System

**File:** `api/game-logic/dab.js` line 198

- `respondRedo` tries to destructure `room.redoRequest.lastMove`
- But `requestRedo` (lines 167-172) never stores `lastMove` or `claimedBox` in the request object
- **Result:** `TypeError: Cannot destructure property 'lineType' of 'undefined'`

### 4. Memory Leak in Frontend

**File:** `pro/src/dab/DabGame.jsx` line 296

- `useEffect` dependency array includes `[socket, players, rows, cols, playLine, playBox]`
- When `players`, `rows`, `cols` change, new socket listeners are added without proper cleanup
- **Result:** Multiple listeners fire for single events

#### 1.4 Fix Event Name: `dab_redoAccepted` → `dab_moveUndone`

**Lines 214-221 - Replace with:**

```javascript
if (accept) {
  const { lineType, r, c } = room.redoRequest.lastMove;
  if (lineType === 'h') {
    room.horizontalLines[r][c] = null;
  } else {
    room.verticalLines[r][c] = null;
  }
  const claimedBox = room.redoRequest.claimedBox;
  if (claimedBox) {
    room.boxes[claimedBox.r][claimedBox.c] = null;
    room.scores[room.redoRequest.requesterIndex]--;
  }
  room.lastMove = null;
  room.lastClaimedBox = null;
  room.currentTurn = room.redoRequest.targetIndex;

  // Emit full state update that frontend expects:
  this.io.to(room.id).emit('dab_moveUndone', {
    horizontalLines: room.horizontalLines,
    verticalLines: room.verticalLines,
    boxes: room.boxes,
    scores: [...room.scores],
    currentTurn: room.currentTurn,
  });
}
```

#### 1.5 Add `dab_startGame` Listener

**Add in handleConnection (line 15):**

```javascript
socket.on('dab_startGame', (data) => this.startGame(socket, data));
```

**Add new method:**

```javascript
startGame(socket, { roomId }) {
  const room = this.rooms.get(roomId);
  if (!room || room.creator !== socket.id) return;
  room.gameState = 'playing';
  this.io.to(roomId).emit('dab_gameStarted', { firstTurn: room.players[0].id });
  this.sendRoomInfo(roomId);
}
```
