# UI/UX Enhancement Plan: Best-in-Class Sketch Game Suite

## Executive Summary

This plan outlines a comprehensive UI/UX overhaul for the socket.io-games suite (Bingo, Dab, TicTacToe, UTTT). The goal is to create a unified "Game Shell" architecture with intentional feedback, consistent layout patterns, and emotional design that matches the sketch aesthetic.

---

## Current State Analysis

### Architecture Issues
- **Code Duplication**: Each game component reimplements room logic, leave handlers, and player displays
- **Inconsistent Layouts**: No unified navigation bar, varying player indicator styles
- **Basic Waiting Room**: Static text, no engagement during pre-game state
- **Simple Leave Flow**: Basic confirm dialog without game state awareness

### UI Patterns Observed
- Sketch-style CSS classes (`sketch-button`, `sketch-card`, `player-badge`)
- Paper-textured background with hand-drawn fonts
- Basic turn indicators with opacity changes
- Confetti popups for wins

## Phase 7: Backend Improvements with TDD

### 7.1 Issues Identified in Backend

**Code Duplication Across Managers:**
- All 4 managers have identical: `leaveRoom`, `reconnect`, `handleDisconnect`, `sendRoomInfo`
- Similar room cleanup patterns (5-minute empty timers)
- Redundant socket event binding patterns

**Missing Validation:**
- No input sanitization for roomId (case sensitivity handled inconsistently)
- Player name length limits not enforced
- No rate limiting on socket events

**State Management:**
- Timers stored in separate Map/inline (inconsistent)
- No room expiration cleanup on server restart
- Missing game statistics tracking

### 7.2 Refactor Plan: Base Game Manager Class

Create `api/game-logic/BaseManager.js` with shared functionality:

```javascript
class BaseGameManager {
  constructor(io) {
    this.io = io;
    this.rooms = new Map();
    this.timers = new Map();
  }

  // Shared: Room cleanup with timers
  registerEmptyTimer(roomId, callback) {
    this.clearTimer(`empty_${roomId}`);
    this.timers.set(`empty_${roomId}`, setTimeout(() => {
      callback();
      this.rooms.delete(roomId);
    }, 5 * 60 * 1000));
  }

  // Shared: Safe player leave
  handlePlayerLeave(socket, roomId, callbacks) {
    const room = this.rooms.get(roomId?.toUpperCase());
    if (!room) return;
    
    const player = room.players.find(p => p.id === socket.id);
    if (!player) return;
    
    player.connected = false;
    callbacks.onPlayerLeft?.({ socket, room, player });
  }

  // Shared: Reconnection
  handleReconnection(socket, roomId, playerId, roomCallbacks) {
    const room = this.rooms.get(roomId?.toUpperCase());
    if (!room) {
      socket.emit(`${this.gamePrefix}_alert`, { icon: 'error', title: 'Error', text: 'Room not found' });
      return false;
    }
    const player = room.players.find(p => p.id === playerId);
    if (!player) {
      socket.emit(`${this.gamePrefix}_alert`, { icon: 'error', title: 'Error', text: 'Player not found' });
      return false;
    }
    socket.join(room.id);
    player.id = socket.id;
    player.connected = true;
    roomCallbacks?.onReconnect?.({ socket, room, player });
    return true;
  }

  clearTimer(key) {
    if (this.timers.has(key)) {
      clearTimeout(this.timers.get(key));
      this.timers.delete(key);
    }
  }

  sanitizeRoomId(roomId) {
    return roomId?.toUpperCase?.() || null;
  }
}
```

describe('Bingo Turn Timer', () => {
  it('should auto-advance turn after 30 seconds of inactivity', function(done) {
    this.timeout(35000);
    
    // Setup: Create room, start game
    player1.emit('bingo_createRoom', 'Alice');
    player1.once('bingo_roomInfo', (room) => {
      player2.emit('bingo_joinRoom', { roomId: room.id, playerName: 'Bob' });
      
      player2.once('bingo_roomInfo', () => {
        player1.emit('bingo_startGame', room.id);
        
        player1.once('bingo_gameStarted', () => {
          // Player1 should be current turn
          // Wait 30 seconds - should auto-advance to player2
          setTimeout(() => {
            player1.once('bingo_nextTurn', (data) => {
              expect(data.nextPlayerId).to.equal(player2.id);
              done();
            });
            player1.once('bingo_alert', (alert) => {
              // Alternative: turn timer event
              done();
            });
          }, 31000);
        });
      });
    });
  });
});
